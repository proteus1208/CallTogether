Free Chrome Speech recognition (no paid API, no local Vosk model). Configure the paste hotkey only.

Paste hotkey

Focus the AI chat input, then press this shortcut to paste the transcript and send Enter.

Why not Vosk?

Chrome MV3 extensions cannot use unsafe-eval. Vosk’s worker needs that, so model load fails even when the .tar.gz is already on disk. CallTogether now uses the built-in Web Speech API instead (no model download).
